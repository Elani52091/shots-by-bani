# Shots by Bugs Photography

## Project Description

Shots by Bugs Photography is a photography website created for a small photography business. The website provides information about the business, its photography services, portfolio and contact details.

The purpose of the website is to create a professional online presence and make it easier for customers to view photography work and make enquiries.
